# Portfolio Knowledge Base

This `.kb` folder is a lightweight guide for maintaining the personal portfolio. It exists to help agents understand the current repository, preserve visual identity, avoid fabricated content, and verify changes without adding enterprise process.

Source code is the final authority. If a knowledge-base document conflicts with implementation, inspect the source file and trust the source.

## Directory Map

- [context/](context/project-overview.md): stable project facts, architecture, styling, content, routing, and deployment notes.
- [workflows/](workflows/small-ui-fix.md): task-specific steps for common portfolio maintenance.
- [patterns/](patterns/component-patterns.md): reusable implementation patterns already present in the app.
- [checklists/](checklists/pre-change-checklist.md): short safety checks before and after edits.

## Keep It Lightweight

Read only the documents relevant to the task. For small copy or spacing fixes, do not turn the task into a broad audit. For routing, deployment, theme, content-model, cursor, particle, or multi-file feature work, read the relevant context and workflow docs first.
